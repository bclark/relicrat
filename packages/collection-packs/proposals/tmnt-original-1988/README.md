# TMNT collection authoring pilot

Status: validation/preview pilot, 2026-11-02. Not an installable pack.

The owner selected original 1988 Playmates basic figures only, one of each of
the ten characters for completion, with variants tracked separately. Accessories,
condition and packaging are optional observations on each physical copy. Title
is the only required intake field. Later reissues do not qualify for this goal.

Files:

- `collection.draft.json`: proposed portable definition and ten-entry checklist.
- `AGENT-PROMPT.md`: copyable authoring instructions to accompany the example.

The `draft_format` marker deliberately differs from the installed version-1 type
definition schema. The collection-authoring preview validates this bounded format through
`POST /api/v1/collection-proposals/preview`. It does not support custom type
installation. Syntax/structure validation does not establish factual accuracy. Do not place this file in a type override directory.

## Intended preview

- Collection: TMNT — Original 1988 figures.
- Reusable type: Action figure.
- Intake: Figure name, then optional accessories, condition, packaging, variant
  notes and general notes. Existing photo and location facilities remain separate.
- Checklist: ten goals, with ownership and completion not yet evaluated.
- Activation creates definitions and checklist entries, never owned copies.

One character can be satisfied by one explicitly reviewed qualifying original
release, regardless of optional paint/sculpt/packaging variations. Duplicates do
not increase the character count. Unknown release eligibility remains unresolved;
no title, character name or barcode alone establishes an original 1988 release.
Accessories and packaging do not gate completion in this pilot. Record absence
explicitly; an omitted observation means unknown, not missing or incomplete.

The source supports the broad ten-character scope. It does not authenticate a
physical copy or establish an exhaustive variant/accessory catalog. The example
intentionally omits product numbers, barcode claims, accessory inventories,
prices and copyrighted imagery. Checklist keys are local identifiers, not global
catalog identities. No shared catalog item or release is created by this file.
