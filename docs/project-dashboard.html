    The recommended sequence

    Recommended priorities. Scheduling will be decided one bounded task at a time.

      Gate before real collection data

      Finish the usable workflow, protect access and uploads, configure persistent storage and secrets, then prove a real operator can restore a coordinated database and media backup. Today’s synthetic rehearsal is evidence for the recovery mechanism, not operational backup coverage.

      Harness improvements alongside product work

      Codify worker startup and publishingMake preflight and the GitHub API publishing path routine. Current runs are deliberately supervised and bounded.

      Add browser checks with the real UIVerify intake, reconciliation, location selection, search and error states end to end.

      Improve reproducibilityLock tested dependencies and image references; current ranges and tags can resolve differently later.

      Keep evidence currentRefresh this report after merged milestones. Test counts and worker state are snapshots, not automatic monitoring.
