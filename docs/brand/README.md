the production identity.

The established creative direction is **Modern collecting. Timeless stories.**
The mascot is the charcoal-gray collector rat with cream muzzle, oversized rounded
ears, burgundy waistcoat and leather satchel. Color families are warm ivory,
charcoal, burgundy, antique gold and forest green. Keep the application modern,
readable and efficient, with restrained brand accents.

The original character concept remains the anatomy reference. Exact production
colors, typography, vector geometry and new character extensions remain subject
to review. The README's use of these proposals does not mark them as final.
Exploratory UI mockups and fictional collectible art are not presented as shipped
screenshots or real collection records.

The wordmarks use self-contained vector paths without external fonts, scripts or
image requests. The README selects the reversed version for a dark color scheme
and preserves the supplied artwork proportions.
